# Simple Weather Forecast App

A clean and simple weather application that fetches and displays current weather data for any city using the OpenWeatherMap API.

## Features

-   **Search by City:** Find the current weather for any city in the world.
-   **Detailed Information:** Displays temperature, a weather icon, condition, humidity, wind speed, and "feels like" temperature.
-   **Dynamic UI:** Handles loading and error states to provide a smooth user experience.
-   **Responsive Design:** The UI is fully responsive and works on mobile and desktop browsers.

## Setup and Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/weather-app.git
    ```
2.  Sign up for a free API key at [OpenWeatherMap](https://openweathermap.org/api).
3.  Open the `script.js` file and replace the placeholder `YOUR_API_KEY` with your actual key.
4.  Open `index.html` in your web browser to run the application.

## Technologies Used

-   HTML5
-   CSS3
-   JavaScript (ES6+ `async/await`, Fetch API)
-   [OpenWeatherMap API](https://openweathermap.org/api)
